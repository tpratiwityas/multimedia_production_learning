Creative Digital Studio Adventure

Simulasi alur kerja produksi multimedia profesional. Kelola proyek video komersial UMKM "Kopi Senja" melewati tahap Praproduksi, Produksi, dan Pascaproduksi dengan 3 Mini Game Interaktif!

⚠️ Penyimpanan browser tidak tersedia (mungkin mode privat). Progres tidak akan bertahan setelah halaman ditutup. Gunakan "Simpan cadangan" sebelum keluar.

🧭 Peta Perjalanan Studio

📘 Cara bermain (urutan yang disarankan)
  1. Isi nama dan pilih peran di bawah.
  2. Baca SOP Produksi (3 tahap + contoh).
  3. Kerjakan 3 Studi Kasus.
  4. Mainkan 3 Mini Game.
  5. Kerjakan Kuis, lalu Proyek dan Refleksi.
  6. Capai 100% untuk membuka Sertifikat. Unduh hasil untuk dikirim ke guru.

Tentang media

Media pembelajaran gamifikasi Alur Kerja Produksi Multimedia untuk siswa DKV Fase F, dikembangkan oleh Kelompok 9 (Literasi TIK dan Media Pembelajaran). Siswa berperan sebagai anggota studio yang menangani proyek video iklan UMKM fiktif "Kopi Senja".

Penyimpanan: progres, nilai, proyek, dan refleksi hanya tersimpan di browser perangkat ini. Tidak ada akun, server, atau pemantauan guru. Identitas tidak diverifikasi.
